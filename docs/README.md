# notes — docs

Knowledge base + task board + AES-256-GCM secret vault (PIN-gated, ciphertext never leaves the server), one-time/public share links, and convert-note-to-published-content.

- **Source:** https://github.com/togo-framework/cms-notes
- **Reference app:** https://fadymondy.com

## Install

```bash
togo install togo-framework/cms-notes
```

The plugin self-registers on blank-import (no manual wiring). See the top-level
README for usage. This plugin was extracted from the fadymondy.com togo app as
part of turning that site into a reusable plugin suite.
